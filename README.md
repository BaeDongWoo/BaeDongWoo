## 안녕하세요, 프론트엔드 개발자 배동우입니다 👋

React와 TypeScript를 주로 사용하며, 결제·송금 웹앱과 이커머스 백오피스의 개발·운영 경험이 있습니다.  
사용자에게 필요한 기능을 구현하고, 운영 중 발견한 문제를 개선하는 데 관심이 있습니다.

코딩 에이전트와 MCP 기반 외부 도구 연동을 개발 과정에 활용한 경험이 있습니다.

## 💼 경력

### 빅스페이먼츠 · 프론트엔드 개발
**2025.07 ~ 2026.06**

#### 결제·송금 웹앱
네이티브 앱 내 React 기반 웹앱 개발·유지보수 및 리뉴얼 담당

- 결제·송금·지갑 관리 및 무기명 선불카드 관련 화면 개발·API 연동
- 카드 신청·잔액 확인·충전·이용 내역 조회 기능 구현
- 모바일 웹뷰 이슈 대응 및 네이티브 수정 필요 항목의 변경 요청
- 이커머스·선불카드 등 사내 서비스 연동 기능 구현

**대표 경험**
- 클라이언트 중심의 서비스 요구를 고려한 React + Vite 전환 제안 및 승인 후 구현
- 레거시 코드·페이지 구조 정리 및 공통 컴포넌트 구성
- 거래 ID 기반 송금 상태 폴링과 완료·실패·지연 안내 개선
- 외부 PG사의 ISP 결제 연동 및 계정별 결제 실패 원인 추적

#### 이커머스 백오피스
신규 MVP 개발 참여 및 이후 기능 개발·유지보수

- 상품 등록·수정·삭제 및 옵션 조합별 가격·재고 관리 기능 개발
- 상품 상세·공지사항 에디터 및 CDN 이미지 연동
- 업체별 데이터 구분 및 요구사항에 따른 탭 구성

**대표 경험**
- 조합 ID와 개별 옵션 ID를 구분한 복합 수정 흐름 구현
- 에디터 후보 비교·시연 및 Tiptap 선정 제안
- 화면·HTML 편집 모드 전환, 이미지 크기 조절·정렬 구현
- 이미지 URL을 포함한 본문 저장 및 재편집 지원

### 피벗 · 프론트엔드 인턴
**2024.09 ~ 2024.11**

- 트레이너·사용자 웹 서비스 유지보수 및 신규 기능 개발
- 트레이너 사이트 화면 개편 및 API 연동
- GA 이벤트 추적 태그 적용 및 온보딩 간소화 작업 참여
