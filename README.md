## 안녕하세요, 프론트엔드 개발자 배동우입니다 👋

React와 TypeScript를 주로 사용하며, 결제·송금 웹앱과 이커머스 백오피스의 개발·운영 경험이 있습니다.  
사용자에게 필요한 기능을 구현하고, 운영 중 발견한 문제를 개선하는 데 관심이 있습니다.

코딩 에이전트와 MCP 기반 외부 도구 연동을 개발 과정에 활용한 경험이 있습니다.

## 💼 경력

**빅스페이먼츠 · 프론트엔드 개발**  
2025.07 ~ 2026.06

- React·TypeScript 기반 결제·송금 웹앱 개발·유지보수 및 리뉴얼
- 결제·송금·무기명 선불카드 연동 및 모바일 웹뷰 대응
- 이커머스 백오피스의 상품·옵션·재고 관리 및 콘텐츠 에디터 개발

**피벗 · 프론트엔드 인턴**  
2024.09 ~ 2024.11

- 트레이너·사용자 웹 서비스 화면 개편 및 API 연동
